### 2.4 故障注入测试

| 故障 | 注入方法 | 期望行为 |
|------|----------|----------|
| STT 服务崩溃 | kill 子进程 | main 检测退出 → 自动重启 → renderer 收到错误提示 |
| TTS 服务不可用 | 不启动 TTS | 对话仍可进行（文字），语音播报降级为静默 |
| whisper 模型缺失 | 删除模型文件 | STT 返回 503 + 明确错误信息 → UI 引导下载 |
| AI 服务超时 | mock 延迟 30s | 超时取消 → 用户收到"AI 无响应"提示 → 不阻塞 UI |
| 磁盘写入失败 | 只读文件系统 | 异步写入捕获错误 → 内存缓存不丢失 → 日志告警 |
| 网络断开 | 禁用网络 | 本地 STT/TTS 正常；web_search 工具返回离线提示 |
| 麦克风权限拒绝 | 系统设置拒绝 | 权限预检返回 false → UI 引导 → 不崩溃 |
| config.json 损坏 | 写入非法 JSON | 加载失败 → 使用默认配置 → 备份损坏文件 → 日志 |

## 3. 测试夹具与隔离环境

### 3.1 语音样本文件（规划新增）

```
tests/fixtures/
  ├─ audio/
  │   ├─ sample_zh_5s.wav      # 中文 5 秒语音（16kHz mono）
  │   ├─ sample_zh_10s.webm    # 中文 10 秒（webm 格式，模拟 MediaRecorder）
  │   ├─ sample_en_5s.wav      # 英文 5 秒
  │   ├─ silence_3s.wav        # 静音 3 秒（测试空转录）
  │   └─ noise_5s.wav          # 环境噪音（测试打断阈值）
  ├─ models/
  │   └─ ggml-tiny.bin         # whisper tiny 模型（CI 用，75MB，git-lfs 或下载）
  └─ config/
      ├─ valid_config.json     # 正常配置
      └─ corrupt_config.json   # 损坏配置（测试容错）
```

### 3.2 隔离原则

- 测试运行时 `ZBOT_DATA_DIR` 环境变量指向 `tests/tmp/`（非 `~/.z-bot/`）
- STT/TTS 测试启动独立端口（18084/18086），避免与开发实例冲突
- Electron E2E 测试用 `electron.launch({ args: ['--test-mode'] })`，禁用全局快捷键注册
- 所有 mock（AI 响应、网络请求）通过 `msw` 或手动 stub，不依赖外部服务
