## 兼容性与回滚策略

1. **每阶段独立分支**：`feat/phase-1-security` → merge → `feat/phase-2-voice` → ...
2. **配置迁移**：Phase 4 密钥加密需兼容旧 config（检测明文 apiKey → 自动迁移 → 删除明文）
3. **Server 协议**：STT/TTS 添加 token 后，旧版 renderer 无法调用 → 同阶段一起更新
4. **回滚粒度**：每个 T 任务为独立 commit，可 `git revert <hash>` 单个回滚
5. **降级开关**：GPU 恢复（T3.10）添加 `--disable-gpu` 命令行参数降级选项
