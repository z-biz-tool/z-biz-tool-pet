# 产品能力与交互优化

> **状态：设计方案，未实现；基线 `cfe55d1`；当前事实=静态代码证据，指标=拟定验收目标**

## 1. 桌面宠物完整交互流程

```
启动 → 托盘图标 + 宠物窗口(透明置顶) → 空闲动画/眨眼/鼠标追踪
  ├─ 拖拽移动 → 贴墙滑下 → 边缘吸附
  ├─ 双击/右键 → 上下文菜单(动画/皮肤/对话/设置)
  ├─ 按住说话(Alt+Shift+V) → 录音 → STT → AI对话 → TTS语音回复 → 情绪动画
  ├─ 语音打断(音量>阈值) → 停止播放 → 重新录音
  ├─ 截图分析(Cmd+Alt+S) → 截屏 → 视觉AI → 结果展示
  ├─ 会议转录 → 录音 → 分块STT → 滚动摘要 → 最终总结
  ├─ 养成互动(喂食/玩耍/洗澡/睡觉/医疗/抚摸) → 属性变化 → 情绪反馈
  └─ 任务调度(cron) → 定时提醒/动画/语音播报
```

## 2. 各环节现状与缺口

### 2.1 宠物窗口与透明置顶

**已有**：`transparent:true, alwaysOnTop:true, frame:false, skipTaskbar:true, hasShadow:false`（`src/main/index.ts` L354-363）

**缺口**：
- 固定 200×320，无用户可调尺寸（P2）
- 多显示器：`getDisplayMatching` 仅用于拖拽边界，`setPetPosition` 用 `getPrimaryDisplay`，跨屏拖拽可能错位（P1）
- HiDPI：未处理 `devicePixelRatio`，Retina 下可能模糊（P2）
- 无"点击穿透"模式（宠物不遮挡底层操作）（P2）
- 无窗口位置持久化，重启后回到默认位置（P1）

### 2.2 动画与状态系统

**已有**：18 种 CSS keyframe 动画 + 优先级打断 + 空闲随机调度 + 眨眼定时器（`src/renderer/pet/animations.ts`）

**缺口**：
- 动画全部 CSS 内联在 `App.tsx` L906-1450（~540 行 style 标签），无独立 CSS 文件（P2 工程化）
- 无骨骼动画/Lottie/GIF 支持，仅 CSS transform，表现力有限（P2）
- 动画与情绪系统耦合：`getEyeShape`/`getMouthShape` 硬编码 switch-case，新增情绪需改多处（P2）
- 贴墙滑下动画在主进程 `setInterval` 30ms 执行（D16），应移至渲染进程 `requestAnimationFrame`（P1）

### 2.3 拖拽与交互

**已有**：mousedown/mousemove/mouseup 全局监听 + IPC `window:movePet`（`src/renderer/pet/App.tsx` L598-625）

**缺口**：
- 未使用 `-webkit-app-region: drag`，每帧 IPC 通信开销大（P1）
- 鼠标追踪 100ms 轮询 IPC（D17），应改为主进程 push 或 `screen` 事件（P1）
- 无惯性/弹性物理效果，拖拽手感生硬（P2）
- 右键菜单为 React 自绘（`contextMenu` state），非原生菜单，无键盘导航（P2）

### 2.4 语音唤醒与识别

**已有**：Push-to-Talk（Alt+Shift+V/C 全局快捷键）+ MediaRecorder 录 webm + fetch STT 服务（`src/renderer/pet/App.tsx` L362-450）

**缺口**：
- **无语音唤醒词**（如"嘿 Z-Bot"），必须手动按键（P1 产品核心）
- whisper.cpp 目录为空（D21），STT 服务实际不可用（P0）
- STT 非流式：录完整段才提交，无实时转录反馈（P1）
- 无录音时长限制/静音自动截断（P2）
- 打断阈值硬编码 30（`INTERRUPT_THRESHOLD`），无用户可调/环境自适应（P2）
- 无麦克风权限预检：首次 `getUserMedia` 可能被系统拒绝但无引导 UI（P1）

### 2.5 对话与反馈

**已有**：AI 多提供商 chat + 情绪关键词提取 + TTS 语音回复 + 气泡展示（`src/renderer/pet/App.tsx` L452-541）

**缺口**：
- pet 端直接 fetch ollama 绕过主进程（D13），无工具调用/多提供商/记忆注入（P0）
- 非流式回复：用户等待完整响应才看到文字，无打字机效果（P1）
- TTS 用 edge-tts 联网（D06），离线环境无语音（P0）
- 对话气泡在 200×320 窗口内空间极小，长文本截断无展开（P2）
- 无对话历史 UI（pet 端），仅 admin 有（P2）

### 2.6 托盘菜单

**已有**：显示萌宠/管理端/语音对话/截图隐身/退出（`src/main/index.ts` L448-521）

**缺口**：
- 菜单构建代码重复两次（D15）（P1）
- 无"最近对话"快捷入口（P2）
- 无宠物状态概览（饥饿/心情）（P2）
- 隐身模式切换后菜单 checkbox 状态需手动重建（已有但代码冗余）

### 2.7 开机自启

**现状**：未实现。`package.json` 无 `auto-launch` 依赖，主进程无 `app.setLoginItemSettings` 调用。

**缺口**：
- 无开机自启能力（P1 桌面宠物核心体验）
- 无"最小化到托盘"启动模式（P2）

### 2.8 多桌面/虚拟桌面

**现状**：未实现。无 `visibleOnAllWork` 设置。

**缺口**：
- macOS Spaces / Windows 虚拟桌面切换后宠物可能消失（P1）
- 应设置 `win.setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })`（P1）

### 2.9 Agent 辅助能力

**已有**：MCP 工具 11 个（web_search/read_url/get_weather/get_datetime/set_reminder/open_app/execute_command/control_pet/screenshot_analyze/clipboard_read/clipboard_write），部分 `requiresConfirmation:true`

**缺口**：
- `execute_command` 虽标记需确认，但 task-system 的 command 类型直接执行无确认（D03）（P0）
- 工具确认 IPC 字段不匹配（D08），确认流程实际不通（P1）
- `toolsCancel` 未实现（D09），取消操作静默失败（P1）
- SQL Agent 模块为无关残留（D24），应移除（P2）
- 无工具执行结果可视化（仅文本返回）（P2）
- 无工具调用频率限制/熔断（P1）
