## 2. Preload 最小暴露

### 2.1 当前过度暴露

| API | 风险 | 建议 |
|-----|------|------|
| `fileRead(filePath)` | 任意路径读取（D05） | 限制为 `~/.z-bot/` + 临时目录 |
| `fileReadAsBase64(filePath)` | 同上 | 同上 + 文件大小限制 10MB |
| `toolsExecute(toolCall)` | 渲染进程可直接触发工具 | 仅允许通过 `ai:chat` 流程间接触发 |
| `captureScreenshot()` | 截屏隐私 | 添加频率限制（1次/5秒） |
| `saveConfig(config)` | 可覆盖 aiApiKey | 敏感字段单独 IPC + 加密 |

### 2.2 改造原则

1. **删除** renderer 不需要的 API（如 `toolsExecute` 应仅由 main 内部调用）
2. **参数校验**：所有接受路径/URL 的 API 在 preload 层做基本格式校验
3. **频率限制**：截图、文件读取添加节流
4. **类型一致**：`global.d.ts` 声明必须与 preload 实现完全匹配（修复 D25）

### 4.2 隐私本地化方案

**原则：所有语音数据（录音、转录文本、合成音频）仅在本地处理，不发送到任何外部服务。**

1. **TTS 本地化**（P0）：
   - macOS: `say` 命令（系统内置，中文 Ting-Ting/Sin-Ji）
   - Windows: SAPI5 `System.Speech.Synthesis`
   - 跨平台: Piper TTS（ONNX Runtime，离线，支持中文）
   - 移除 `edge_tts` 依赖

2. **临时文件管理**（P0）：
   - 所有音频临时文件写入 `os.tmpdir()/zbot-<random>/`
   - 处理完成后立即 `fs.unlinkSync`
   - 注册 `process.on('exit')` 清理残留
   - 从 git 历史移除 `server/temp_audio.webm`，添加 `.gitignore` 规则

3. **STT 本地化确认**（已满足）：
   - whisper.cpp 为纯本地推理，无网络调用 ✅
   - 需确保模型文件本地存储，不依赖远程下载（首次引导用户手动下载）

4. **会议录音加密**（P1）：
   - 转录文本存储前用 `electron.safeStorage.encryptString` 加密
   - 原始音频文件在转录完成后立即删除
   - 最终摘要加密存储到 `~/.z-bot/meetings/`

## 6. 密钥存储

### 6.1 当前问题

`aiApiKey` 明文存储在 `~/.z-bot/config.json`（H01），任何本地进程可读取。

### 6.2 方案

```typescript
import { safeStorage } from 'electron';

// 加密存储
function saveApiKey(key: string): void {
  const encrypted = safeStorage.encryptString(key);
  fs.writeFileSync(path.join(dataDir, 'api_key.enc'), encrypted);
}

// 解密读取
function loadApiKey(): string | null {
  const encPath = path.join(dataDir, 'api_key.enc');
  if (!fs.existsSync(encPath)) return null;
  const encrypted = fs.readFileSync(encPath);
  return safeStorage.decryptString(encrypted);
}

// config.json 中不再存储 aiApiKey 字段
// 迁移：首次启动检测旧 config 中的 apiKey，加密后删除明文字段
```

**平台支持**：
- macOS: Keychain ✅
- Windows: DPAPI ✅
- Linux: libsecret（需 gnome-keyring/kwallet）⚠️ 降级为文件权限 600
