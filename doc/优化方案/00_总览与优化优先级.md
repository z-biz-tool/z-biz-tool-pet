## 1. 项目定位与独特价值

Z-Bot 是一款 **Electron 桌面宠物助手**，核心价值区别于通用 AI 对话工具：

- **常驻陪伴**：透明置顶小窗（200×320）+ 系统托盘，始终可见、不打扰
- **养成情感连接**：6 维属性（hunger/happiness/energy/cleanliness/health/affection）+ 4 阶段生命周期 + 19 种情绪 + 离线衰减
- **语音优先交互**：按住说话 → whisper.cpp 本地 STT → AI 对话 → edge-tts 语音回复 → 音量打断
- **MCP 工具扩展**：11 个工具（web_search/read_url/get_weather/screenshot_analyze/execute_command 等），部分需用户确认
- **会议转录**：ffmpeg 录音 → 10 秒分块 STT → 滚动摘要 → 最终总结

对标 Desktop Pet / Shimeji 理念，但集成 AI 对话与工具调用能力。

## 2. 技术栈确认

| 层级 | 技术 | 证据 |
|------|------|------|
| 框架 | Electron 41.2.1 | `package.json` dependencies |
| 渲染 | React 19 + Vite 8 + TypeScript + Antd 6 + Zustand | `package.json`, `vite.config.ts` |
| 主进程 | CommonJS, ES2020 | `tsconfig.main.json` |
| Preload | contextBridge, contextIsolation:true | `src/preload/index.ts` |
| 后端服务 | Express (STT:8084, TTS:8086) | `server/stt.js`, `server/tts.js` |
| 语音识别 | whisper.cpp CLI 子进程 | `server/stt.js` L67 |
| 语音合成 | Python edge-tts（联网微软服务） | `server/tts_local.py` L8 |
| 构建 | tsc + vite build（无 electron-builder 配置） | `package.json` scripts |

**非 Tauri**：无 `src-tauri/`、无 `Cargo.toml`、无 `capabilities/` 目录。

## 5. 分阶段能力演进

- **Phase 1（安全加固）**：修复 P0、关闭 no-sandbox、工具确认机制、密钥加密
